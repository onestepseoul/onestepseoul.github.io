이 페이지에서 고친 내용은 맨 아래 [저장하고 사이트에 반영]을 누를 때 사이트의 config.json으로 커밋되어, 약 20~30초 뒤 https://onestepseoul.github.io/ 에 그대로 나타납니다. 처음 한 번만 GitHub 토큰을 넣으면 되고, 토큰은 이 브라우저에만 저장됩니다.

⇄어느 페이지를 고칠까요?

탭을 고르면 그 페이지의 설정 파일을 불러옵니다. 저장하면 고른 페이지의 파일에만 반영되고, 다른 페이지는 그대로 남습니다. 토큰은 두 페이지가 같이 씁니다.

1상단 문구 (첫 화면)

방문자가 가장 먼저 보는 부분입니다. **굵게** 로 감싸면 굵게 표시됩니다.

마감 임박 문구 바꾸기 ▾

3혜택 2 · 소상공인 추가 혜택 (카드)

숏폼 영상·세무기장처럼 후기 이벤트와 별개로 안내하는 혜택 카드입니다. 카드마다 배지·제목·설명·목록을 고칠 수 있습니다.

문의 고객용 페이지의 ‘안심 안내’ 3개 (support.html 전용) ▾

support.html 에만 나오는 섹션입니다. 시공 고객용(index.html)에는 표시되지 않습니다.

4시공 사진 3장

핸드폰 사진을 그대로 고르면 자동으로 줄여서(가로 1600px) 저장소 images/ 폴더에 올라갑니다. 외부 이미지 주소를 직접 넣어도 됩니다.

사진 파일은 고르는 순간 저장소에 커밋됩니다(사이트에는 아직 안 보임). [저장하고 사이트에 반영] 을 눌러야 페이지에 나타납니다.

5실제 후기 · 시공 사례 문구

실제 시공 후기를 넣어 주세요. 임의의 후기를 쓰면 표시광고법 위반이 될 수 있습니다.

6신청서 · 동의 문구

동의 문구는 법적으로 중요합니다. [필수]와 [선택]은 체크박스가 따로 있어야 합니다(개인정보 보호법 제22조). 문구를 바꿀 때는 약관도 같은 내용으로 맞춰 주세요.

입력 항목은 페이지에 고정되어 있습니다. (시공 고객: 성함 · 연락처 · 가게명 · 후기 링크 또는 당근 닉네임 / 미시공 고객: 성함 · 연락처 · 가게명 · 희망 혜택) 칸 이름만 아래에서 바꿀 수 있습니다.

⚙GitHub 연결 (처음 한 번만)

사이트가 GitHub Pages라서, 저장하려면 이 저장소에 글을 쓸 수 있는 열쇠(토큰)가 필요합니다.

토큰을 넣으면 연결을 확인합니다.
토큰 발급 방법 (3분, 클릭해서 펼치기) ▾
  1. github.com/settings/personal-access-tokens/new 를 엽니다. (GitHub 로그인이 안 되어 있으면 먼저 로그인)
  2. Token name 에 아무 이름이나 적습니다. 예: onestep-landing-admin
  3. Expiration 은 90 days 또는 1 year 중 편한 것으로 고릅니다. (만료되면 이 페이지에서 새 토큰을 넣으면 됩니다)
  4. Repository access → Only select repositories → onestepseoul/onestepseoul.github.io 하나만 선택합니다.
  5. Permissions → Repository permissions 를 펼쳐 Contents 를 Read and write 로 바꿉니다. (나머지는 그대로 두세요. Metadata는 자동으로 Read-only가 됩니다)
  6. 맨 아래 Generate token 을 누르고, 화면에 한 번만 보이는 github_pat_... 를 복사합니다.
  7. 위 입력란에 붙여넣고 토큰 저장하고 연결 확인 을 누릅니다. 연결됨 이 나오면 끝입니다.
이 관리자 페이지는 주소를 아는 사람이면 누구나 열 수 있지만(검색에는 노출되지 않음), 토큰이 없으면 아무것도 저장할 수 없습니다. 공용 컴퓨터에서는 쓰고 나서 토큰 삭제 를 눌러 주세요. 토큰이 새어 나간 것 같으면 GitHub 설정에서 그 토큰을 Revoke 하면 됩니다.
