## 1. 관리자 페이지 사용법 (처음 3분, 그다음부터는 30초)

1. **https://onestepseoul.github.io/admin.html** 를 엽니다. (휴대폰·PC 모두 됩니다. 검색에는 노출되지 않습니다)
2. 맨 위 **1번 카드**의 [토큰 발급 방법]을 펼쳐 안내대로 **GitHub Fine-grained 토큰**을 만듭니다.
   - 링크: https://github.com/settings/personal-access-tokens/new
   - Repository access → **Only select repositories** → `onestepseoul/onestepseoul.github.io` 하나만
   - Permissions → Repository permissions → **Contents: Read and write** (나머지는 그대로)
   - 만료(Expiration)는 90일 또는 1년 중 편한 것
3. `github_pat_...` 를 복사해 입력란에 붙여넣고 **[토큰 저장하고 연결 확인]** → “**연결됨**”이 나오면 끝.
   - 토큰은 **그 브라우저(localStorage)에만** 저장됩니다. 페이지 소스·서버에는 남지 않습니다. 공용 PC에서는 쓰고 나서 **[토큰 삭제]**.
   - **두 페이지가 같은 토큰을 씁니다.** 페이지마다 따로 만들 필요 없습니다.
4. **페이지 선택 탭**에서 고릅니다.
   - `🛠️ 시공 고객용 (후기 이벤트 · index.html)` → `config.json`
   - `🏪 문의 고객용 (숏폼·세무기장 · support.html)` → `config-support.json`
   - 탭을 바꾸면 그 페이지의 설정을 새로 불러옵니다. 마지막으로 고른 탭은 기억됩니다.
   - 저장 안 한 변경이 있으면 탭을 옮기기 전에 확인창이 뜹니다.
5. 아래 카드에서 글자·금액·링크·FAQ·약관 등을 고칩니다. (카드 순서: 기본·링크 / 상단 문구 / 혜택1 / 혜택2 / 사진 / 후기 / 신청서 / 약관 / 연락처 / FAQ / 고급)
   - **문의 고객용 탭**에서는 `사진`·`실제 후기` 카드가 숨겨지고, 대신 **혜택 2번 카드 안의 [안심 안내 3개]** 가 열립니다(support.html 전용 섹션).
6. 맨 아래 **[저장하고 사이트에 반영]** → “저장 완료 (커밋 …)” → **약 20~30초** 뒤 그 페이지에 적용됩니다.
   - 저장은 **현재 탭의 파일 하나에만** 커밋됩니다. 다른 페이지는 그대로 남습니다.
7. **사진**: 6번 카드에서 파일을 고르면 자동으로 줄여서(가로 1600px, JPEG) 저장소 `images/` 로 올라갑니다. 사진은 고르는 순간 저장소에 커밋되고, **페이지에 나타나려면 저장을 한 번 더** 눌러야 합니다. (시공 고객용 페이지에만 있는 카드입니다)
8. **[미리보기]** 는 저장 전 내용을 새 창에서 보여줍니다(내 브라우저에만). 탭에 맞춰 `index.html?draft=1` 또는 `support.html?draft=1` 이 열립니다. **[불러온 값으로 되돌리기]** 는 사이트에 올라가 있는 내용으로 되돌립니다.

**문구 규칙**: `**이렇게**` = 굵게 · 줄바꿈은 엔터 · 약관에서 `[[…]]` 는 강조 배경 · `{{privacyOfficer}}` 는 10번의 개인정보 보호책임자 값으로 자동 치환.

## 3. 어떻게 반영되나 (구조)

```
관리자 페이지(admin.html)  ← 탭으로 페이지 선택
   │  ① GET  /repos/.../contents/config.json  또는 config-support.json   → 최신 sha 확인
   │  ② PUT  같은 파일                                                    → base64(JSON) 커밋
   ▼
GitHub 저장소 config.json / config-support.json  ──(Pages 빌드 20~30초)──▶  사이트
                                                              │
      index.html  → fetch('config.json?t=…')       ─┐
      support.html→ fetch('config-support.json?t=…')─┴─▶ 화면에 반영 (실패 시 내장 기본값)
```

- `?t=Date.now()` 로 주소를 매번 바꿔 **캐시된 옛 파일을 물지 않게** 했습니다. (GitHub Pages는 `cache-control: max-age=600` 이라 캐시 회피가 없으면 최대 10분 묵은 내용이 보일 수 있습니다)
- 저장이 충돌(409)하면 sha를 다시 받아 **한 번 자동 재시도**합니다. 파일이 없으면(404) sha 없이 새로 만듭니다.
- 설정 JSON 두 개는 **공개 파일**입니다(누구나 읽을 수 있음). 쓰기만 토큰이 필요합니다.

## 4. 개인별 마감 링크

```
시공 고객용 : https://onestepseoul.github.io/?d=3&code=A12
문의 고객용 : https://onestepseoul.github.io/support.html?d=3&code=B07
```

| 값 | 뜻 |
|---|---|
| `d=3` | 3일 남음 (오늘 포함 3일째 되는 날 23:59 마감) → “신청 마감 : 11월 29일 (일) 23:59” |
| `d` 없음 | 기본 5일 (`settings.defaultDays`, 관리자 2번 카드) |
| `until=2026-12-02` | 특정 날짜로 고정 (`d`보다 우선) |
| `code=B07` | 고객번호 표시 + 네이버 폼 주소 뒤에 `&code=B07` 로 전달 (관리자 2번 카드에서 끌 수 있음) |

엑셀에서 한 번에 만들기 — 고객번호가 A열, 남은 일수가 C열이면 B2에:
`="https://onestepseoul.github.io/support.html?d="&C2&"&code="&A2`

**주의**: `d`는 실제 회차 마감일을 넘기지 마세요. 실제 마감이 11/29인데 `d=10`을 주면 거짓 마감 표시가 됩니다(표시광고법).

## 9. 법적으로 손본 부분 — 3줄

1. **한 번에 동의**: 체크 1개, 그 위에 굵고 큰 한 줄(시공: “후기 이벤트 참여와 함께, 숏폼 영상 제작(월 4회)과 세무기장(1개월) 무료 혜택 안내를 받는 것에 동의합니다.” / 문의: “숏폼 영상 제작(월 4회)과 세무기장(1개월) 무료 혜택을 신청하며, 담당자의 안내 연락과 개인정보 수집·이용에 동의합니다.”)이 가장 잘 보이는 자리에 있습니다.
